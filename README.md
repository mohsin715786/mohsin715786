## 🚀 Featured Project

### Peer-Link — Campus P2P Marketplace

A Flutter and Firebase-based peer-to-peer marketplace designed for campus communities.

**Core features include:**

- 🔐 Firebase Authentication
- 💬 Real-time messaging
- 🔔 Firebase Cloud Messaging notifications
- 🔎 Search and filtering
- ☁️ Firebase Cloud Storage
- 🧩 Modular / layered architecture
- ⚙️ GitHub Actions CI/CD
- 📱 Cross-platform Flutter interface

**Tech Stack**

`Flutter` `Dart` `Firebase` `Firestore` `Riverpod` `FCM` `GitHub Actions`
